`docs/reference/StudentKanban-Dossier-Original.pdf`

## How to use the dossier

- Cite its requirement/use-case identifiers in Issues and pull requests.
- Put team interpretation and clarifications in the relevant Markdown document.
- Record approved deviations in `docs/collaboration/decisions/`.
- Do not treat an unimplemented requirement as a completed feature.
