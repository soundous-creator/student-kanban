## How to use the dossier

- Treat the PDF as immutable; do not edit or replace the source.
- Cite requirement/use-case identifiers in Issues and pull requests.
- Put team interpretation and clarifications in the relevant Markdown documents.
- Record approved deviations in `docs/collaboration/decisions/`.
- Do not treat an unimplemented requirement as a completed feature.
