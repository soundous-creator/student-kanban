**Status: draft — team confirmation required**

## 1. Project identity

StudentKanban is a proposed offline desktop tool for students who need to organize several university modules and the tasks associated with them.

## 3. Problem statement (derived from the dossier)

Students handling multiple modules, practical assignments, projects, and revision activities may need one lightweight place to organize tasks, see progress, record priorities and time, and keep relevant local files accessible. The proposed application addresses this by offering a local Kanban workflow that remains usable without an Internet connection.

## 4. Intended outcome

A student should be able to manage modules and their tasks, move tasks through three statuses, track basic effort, search tasks, use a simple checklist, attach a local file path, and retain information between application sessions.
