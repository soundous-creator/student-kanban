# Meeting notes

Create one Markdown file per real meeting, named `YYYY-MM-DD-topic.md`.

Use this structure:

- Date and time:
- Participants:
- Purpose:
- Topics discussed:
- Decisions made:
- Open questions:
- Action items (owner and target date):
- Links to related Issues/PRs:

Only record meetings that actually occurred. Distinguish confirmed decisions from suggestions and unresolved questions.
